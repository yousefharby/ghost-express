# موقع Ghost Express

موقع عرض لشركة الشحن (عربي، RTL) + لوحة تحكم. السيستم نفسه (تطبيق الراسل، تطبيق المندوب، سيستم الويب) منفصل، والموقع بيوديله بلينكات بس.

## الصفحات

| الملف | الصفحة |
| --- | --- |
| `index.html` | الرئيسية |
| `track.html` | تتبع شحنتك |
| `about.html` | من نحن |
| `prices.html` | الأسعار + حاسبة سعر المحافظة |
| `apps.html` | تطبيقاتنا |
| `integrations.html` | التكاملات |
| `contact.html` | تواصل معانا |
| `register.html` | افتح حساب تاجر |
| `terms.html` | الشروط والأحكام |
| `admin.html` | لوحة التحكم |

## الرفع على الاستضافة (لازم PHP 8 أو أحدث)

1. افتح `config.php` وغيّر `ADMIN_PASSWORD` لكلمة مرور قوية.
2. ارفع كل الملفات والفولدرات زي ما هي على `public_html` (Hostinger أو أي استضافة cPanel).
3. اتأكد إن فولدر `data` ليه صلاحية كتابة (755 أو 775).
4. افتح `yourdomain.com/admin.html` وادخل كلمة المرور. من جوه اللوحة تقدر تغيّرها بعد كده.

مفيش قاعدة بيانات محتاجة تتعمل: الطلبات والرسائل والأسعار بتتحفظ كملفات جوه `data` ومحدش يقدر يفتحها من المتصفح.

## لوحة التحكم

- **طلبات فتح حساب**: كل اللي سجل من صفحة "افتح حساب"، مع زرار واتساب واتصال، وتغيير الحالة، وتصدير Excel.
- **الرسائل**: اللي اتبعت من صفحة "تواصل معانا" (استفسار، شكوى، ربط متجر، شغل مندوب).
- **الأسعار**: أسماء الباقات وأسعار السبع مناطق ومدة التوصيل والملاحظات.
- **بيانات الموقع**: التليفون، الواتساب، السوشيال، أرقام الصفحة الرئيسية، ولينكات السيستم.

## الربط مع السيستم (Mega)

من **بيانات الموقع** حط اللينكات اللي هتاخدها من الشركة اللي عاملة السيستم:

- **لينك دخول التجار**: بيظهر زرار "دخول التجار" في الهيدر والفوتر.
- **لينك صفحة التتبع**: اكتب `{code}` مكان رقم الشحنة، مثلاً `https://system.example.com/track?code={code}`. لو فاضي، التتبع بيحوّل العميل لواتساب برقم الشحنة.
- **لينكات التطبيقات**: Google Play و App Store وتطبيق المندوب. لو فاضية، الزراير بتظهر "قريباً".

## لو الاستضافة من غير PHP

الموقع كله هيشتغل عادي، بس الفورمز هتتحفظ على متصفح الزائر بس (وضع تجريبي) ومش هتوصل للوحة التحكم. زرار واتساب في الفورمز بيفضل شغال.

## تعديل المحتوى

- النصوص جوه ملفات الـ HTML مباشرة.
- الأسعار والأرقام الافتراضية في `assets/js/data.js` (اللي بيتحفظ من لوحة التحكم بياخد الأولوية).
- بعد ما الدومين يبقى جاهز، غيّر `og:image` في كل صفحة لرابط كامل (مثلاً `https://yourdomain.com/assets/img/og-image.jpg`) عشان الصورة تظهر لما حد يشارك اللينك.
